# Security Policy

## Supported Versions

The latest
[GIT tagged version of cockpit-virtual-machines-setup](https://github.com/frnmst/cockpit-virtual-machines-setup/tags)
is the only one supported. When a new version is released, that one will be the
only one supported.

## Reporting a Vulnerability

Send me an [email](mailto:solvecomputersciencecollabs+SECURITY-cockpit-virtual-machines-setup@gmail.com?subject=report%20md-toc%20vulnerability&body=Please%20encrypt%20before%20sending), preferably encryped.
